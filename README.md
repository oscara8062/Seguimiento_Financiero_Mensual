# FinaTrack

Aplicación de escritorio para el seguimiento financiero mensual: permite registrar ingresos y gastos personales, organizarlos por mes y llevar un control claro de las finanzas propias.

## Descarga

Para descargar el programa de escritorio, dirígete a:

👉 https://github.com/oscara8062/Seguimiento_Financiero_Mensual/releases/tag/FinaTrack

Allí encontrarás el instalador junto con las instrucciones para instalarlo y usarlo.
